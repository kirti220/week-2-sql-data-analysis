# Week 2 – SQL for Data Analysis

## Project Overview

This project was completed as part of my Data Analyst Internship – Week 2 assignment.

The project focuses on using SQL for analyzing a sales dataset containing 200 records.

## Dataset

The dataset contains sales transaction information including:

- Order ID
- Customer Name
- Order Date
- Category
- Sub-category
- Product Name
- Quantity
- Unit Price
- Total Price
- Region

## SQL Concepts Used

The project demonstrates:

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- SUM
- AVG
- JOIN
- Subqueries
- CASE statements

## Key Analysis

The analysis includes:

1. Total number of orders
2. Total sales
3. Average order value
4. Top 10 customers
5. Sales by category
6. Average order value by category
7. Sales by region
8. Orders above average order value
9. Order value classification using CASE
10. Joining sales data with category information

## Key Results

| Metric | Result |
|---|---:|
| Total Orders | 200 |
| Total Sales | 2,420,107 |
| Average Order Value | 12,100.54 |

| Lowest Order Value | 292 |
